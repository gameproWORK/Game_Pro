# 🎮 Game Pro

เว็บแอปสำหรับค้นหาเกมจาก Steam และจัดการรายการเกมที่สนใจ ผู้ใช้สามารถค้นหาเกม ดูรายละเอียด เพิ่มเกมลง **ตะกร้า** และย้ายเกมที่เลือกเข้าสู่ **คลังเกมส่วนตัว** พร้อมบันทึกและแก้ไขชั่วโมงที่เล่นได้ ระบบรองรับการเข้าสู่ระบบด้วยบัญชี Google

## ✨ ฟีเจอร์หลัก

1. **ระบบเข้าสู่ระบบ (Authentication):** เข้าสู่ระบบด้วยบัญชี Google ผ่าน Auth.js / NextAuth v5 beta
2. **หมวดหมู่เกม:** เลือกดูเกมตามหมวด **แนะนำ · ขายดี · ลดราคา · มาใหม่ · เร็ว ๆ นี้** ดึงข้อมูลจาก Steam Store API พร้อมชื่อเกม ภาพปก และราคา
3. **ค้นหาเกม:** ค้นหาเกมจาก Steam ด้วยชื่อเกม และแสดงผลลัพธ์ที่ตรงกับคำค้นหา
4. **รายละเอียดเกม:** เปิดหน้ารายละเอียดของเกม โดยดึงข้อมูลจาก Steam Store API ตามรหัสเกม (App ID)
5. **ตะกร้าเกม:** เพิ่มเกมที่สนใจลงตะกร้า และนำเกมออกจากตะกร้าได้
6. **คลังเกมส่วนตัว:** ย้ายเกมจากตะกร้าเข้าคลังเกม บันทึกและแก้ไขชั่วโมงที่เล่น รวมถึงลบเกมออกจากคลัง
7. **จัดการข้อมูลฝั่งผู้ใช้:** เก็บข้อมูลตะกร้าและคลังเกมใน `localStorage` โดยใช้คีย์ที่แยกตามบัญชีผู้ใช้
8. **สิทธิ์แอดมิน:** มีการตรวจสอบอีเมลแอดมินเพื่อเปิดความสามารถจัดการเกมในคลังตามที่ระบบกำหนด
9. **ตรวจสอบข้อมูล:** ใช้ Zod กำหนดและตรวจสอบรูปแบบข้อมูลที่เกี่ยวข้องกับเกม

## 💻 วิธีติดตั้งและรันโปรเจกต์ในเครื่อง

1. **แตกไฟล์ ZIP** หรือ Clone โปรเจกต์จาก GitHub จากนั้นเปิดโฟลเดอร์ `Game_Pro-master`

2. **ติดตั้งแพ็กเกจ**

    ```bash
    npm install
    ```

3. **ตั้งค่า Environment Variables** โดยสร้างไฟล์ `.env.local` ที่โฟลเดอร์หลักของโปรเจกต์

    ```env
    AUTH_SECRET=<ค่าสุ่มลับสำหรับ Auth.js>
    AUTH_GOOGLE_ID=<Google OAuth Client ID>
    AUTH_GOOGLE_SECRET=<Google OAuth Client Secret>
    ```

    สามารถสร้างค่า `AUTH_SECRET` ได้ด้วยคำสั่ง:

    ```bash
    npx auth secret
    ```

    สร้าง OAuth Client ใน Google Cloud Console และเพิ่ม Authorized redirect URI:

    ```text
    http://localhost:3000/api/auth/callback/google
    ```

4. **รันโปรเจกต์ในโหมดพัฒนา**

    ```bash
    npm run dev
    ```

    เปิดเว็บไซต์ที่ `http://localhost:3000`

5. **ตรวจสอบการ build สำหรับใช้งานจริง (ถ้าต้องการ)**

    ```bash
    npm run build
    npm run start
    ```

## 🔌 API

โปรเจกต์เรียกใช้ Steam Store API ผ่านฟังก์ชันใน `src/lib/steam/api.ts` และมี API Routes ภายใน Next.js สำหรับให้หน้าเว็บเรียกใช้งาน

| Endpoint ภายในโปรเจกต์ | Method | หน้าที่ |
| --- | --- | --- |
| `/api/steam/featured?category=<หมวด>` | GET | ดึงรายการเกมตามหมวด: `all` (ค่าเริ่มต้น), `top_sellers`, `specials`, `new_releases`, `coming_soon` |
| `/api/steam/search?q=<คำค้นหา>` | GET | ค้นหาเกม โดยคำค้นหาต้องมีความยาว 2–80 ตัวอักษร |
| `/api/steam/games/<appId>` | GET | ดึงรายละเอียดเกมจาก Steam ตาม App ID |
| `/api/auth/[...nextauth]` | GET / POST | จัดการเส้นทางการยืนยันตัวตนของ Auth.js |

### Steam Store API ที่ใช้

| URL | หน้าที่ |
| --- | --- |
| `https://store.steampowered.com/api/featuredcategories/?cc=th&l=thai` | ดึงหมวดหมู่เกมแนะนำจาก Steam Store |
| `https://store.steampowered.com/api/storesearch/` | ค้นหาเกมในร้าน Steam |
| `https://store.steampowered.com/api/appdetails` | ดึงรายละเอียดเกมตาม App ID |

## ⚠️ ข้อจำกัด

- ข้อมูลตะกร้าและคลังเกมจัดเก็บใน `localStorage` ของเบราว์เซอร์ จึงไม่ซิงก์ข้ามอุปกรณ์หรือเบราว์เซอร์
- การแยกข้อมูลตามบัญชีใช้คีย์ที่สร้างจากอีเมลหรือรหัสผู้ใช้ แต่ข้อมูลยังอยู่ในเบราว์เซอร์เครื่องนั้น ไม่ใช่ฐานข้อมูลส่วนกลาง
- โปรเจกต์ไม่มีฐานข้อมูลกลางสำหรับตะกร้าและคลังเกม หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์ ข้อมูลที่เก็บใน `localStorage` อาจหายไป
- ข้อมูลเกมและราคาอ้างอิงจาก Steam Store API ซึ่งอาจเปลี่ยนแปลงตามภูมิภาค เวลา หรือการให้บริการของ Steam
- การเข้าสู่ระบบ Google ต้องตั้งค่า OAuth credentials ใน `.env.local` ให้ถูกต้องก่อนใช้งาน
- หมวดหมู่เกมอ้างอิงหมวดที่ Steam ส่งมาให้ บางช่วงเวลาบางหมวด (เช่น "เร็ว ๆ นี้") อาจมีเกมน้อยหรือไม่มีเลย
